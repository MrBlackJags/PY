# Echoes of the Wild — Extinct Animals Educational Website

An educational, interactive web project built with modern semantic HTML5, responsive CSS3, and vanilla JavaScript dedicated to teaching people about extinct animals, their biology, causes of extinction, and conservation lessons.

---

## 🌟 Pages & Features

1. **Species Explorer (`index.html`)**:
   - **Interactive Animal Cards**: Includes featured extinct species such as the Woolly Mammoth, Dodo, Tasmanian Tiger (Thylacine), Sabre-toothed Cat (Smilodon), Passenger Pigeon, Quagga, Irish Elk, Great Auk, and Steller's Sea Cow.
   - **Real-Time Search & Category Filters**: Search dynamically by name, scientific binomial, habitat, or diet, and filter by epoch (Ice Age, Historical, Modern Era).
   - **Detailed Dossier Modal**: Click on any animal to view detailed records including extinction period, native habitat, primary extinction causes, fascinating facts, and lessons for modern conservation.

2. **Extinction Timeline (`timeline.html`)**:
   - Visual historical journey through major extinction pulses:
     - The Quaternary Megafaunal Collapse (~10,000 BCE)
     - The Age of Oceanic Exploration & Island Fragility (1500s–1700s)
     - Industrial Harvesting & Mass Deforestation (1800s–1900s)
     - The Anthropocene and modern conservation interventions.

3. **Interactive Quiz (`quiz.html`)**:
   - Multiple-choice trivia system that tests users on paleo-conservation knowledge with immediate feedback, explanations, and final score reporting.

---

## 🚀 How to Run

Because this is a pure front-end web project, no build tools or package managers are required.

Simply open [`index.html`](index.html) in any modern web browser, or serve it locally using Python:

```bash
# Python 3
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.
